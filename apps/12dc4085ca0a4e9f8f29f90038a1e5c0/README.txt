Генератор кроссвордов
=====================

Офлайн-приложение: генерирует небольшие кроссворды из встроенного словаря,
позволяет вводить ответы и проверять их. Полностью работает в браузере,
без сервера, без сетевых запросов, без хранения данных.

Возможности
-----------
- Три размера кроссворда: маленький (9x9), средний (11x11), большой (13x13).
- Случайная генерация сетки из встроенного словаря (~65 слов).
- Ввод ответов прямо в клетки; навигация стрелками; Пробел меняет направление.
- Проверка ответов: неверные клетки подсвечиваются, показывается сводка.
- Показ правильных ответов и очистка сетки.
- Работает в iframe sandbox="allow-scripts" и при открытии через file://.

Управление
----------
- Клик по клетке - фокус ввода.
- Стрелки - перемещение по сетке; задают направление ввода.
- Пробел - смена направления (по горизонтали / по вертикали).
- Backspace - стереть букву; на пустой клетке - перейти к предыдущей.
- Кнопки "Проверить", "Показать ответы", "Очистить", "Новый кроссворд".

Ограничения
-----------
- Словарь встроенный и небольшой (~65 слов), поэтому повторы между
  генерациями относительно частые.
- Поддерживается только кириллица. Латинские буквы, визуально совпадающие
  с кириллическими (A, B, C, E, H, K, M, O, P, T, X), автоматически
  заменяются на кириллические. Остальные латинские символы игнорируются.
- Буква "ё" в ответах кроссворда заменена на "е" - так принято в русских
  кроссвордах. Если ввести "ё", она будет заменена на "е".
- Кроссворд не "плотный": используется жадный алгоритм с несколькими
  попытками. В сетке могут оставаться белые пустые клетки.
- Прогресс не сохраняется между перезагрузками страницы (localStorage
  может быть недоступен в iframe sandbox, поэтому не используется).
- Приложение не отправляет никаких данных наружу.

Источники и проверка данных
---------------------------
- Слова и определения составлены вручную для этого приложения. Они не
  претендуют на полноту и не являются словарными определениями из
  академических источников.
- Генератор не использует таблицы, формулы или коэффициенты, поэтому
  проверять внешние источники не требуется.
- Тестирование в реальном браузере не проводилось. Проверено:
  - синтаксическая корректность JS (визуальный осмотр);
  - отсутствие внешних сетевых запросов (нет fetch, XMLHttpRequest,
    <link href="http...">, <script src="http..."> и т. п.);
  - совместимость с sandbox="allow-scripts" (не используются
    localStorage, IndexedDB, cookies, clipboard, window.open,
    parent.document, postMessage);
  - отсутствие обязательных ES-модулей и сборщиков (только обычные
    скрипты с defer).
  Не проверено вживую: визуальный рендер, поведение мобильных клавиатур,
  работа в конкретных версиях браузеров. Если что-то пойдёт не так -
  опишите проблему, доработаю.

Файлы
-----
- index.html - точка входа
- style.css - оформление
- app.js - логика приложения
- data.js - встроенный словарь (слово + определение)
- README.txt - этот файл

Как встроить
------------
1. В локальной админке Tree Studio создайте страницу.
2. Загрузите ZIP - админка распакует файлы в папку приложения.
3. Выберите index.html как точку входа.
4. Сохраните и экспортируйте сайт.
5. Рекомендуемая высота iframe: 1100 px (минимум 700 px).

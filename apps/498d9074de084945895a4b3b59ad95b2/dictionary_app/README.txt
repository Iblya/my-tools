АНГЛО-РУССКИЙ СЛОВАРЬ (ОФЛАЙН)

1. НАЗНАЧЕНИЕ
Приложение для быстрого поиска английских слов и их русских переводов.
Работает полностью в браузере, не требует интернета, сервера или установки.

2. СОСТАВ АРХИВА
- index.html — точка входа
- style.css — оформление
- app.js — логика поиска
- data.js — словарные данные
- README.txt — этот файл

3. УСТАНОВКА
1) Загрузите ZIP в локальную админку Tree Studio.
2) Создайте страницу приложения и укажите index.html в качестве точки входа.
3) Сохраните и экспортируйте сайт.
4) Опубликуйте статические файлы.

4. КАК ДОБАВИТЬ БОЛЬШЕ СЛОВ
Откройте data.js и добавьте записи в объект window.DICTIONARY по образцу:

"word": { "translation": "перевод", "pos": "часть речи", "example": "пример" }

Ключом является английское слово. Поле translation обязательно, pos и example — необязательны.
Рекомендуемый объём — до 20 000–30 000 слов для сохранения быстродействия.

5. ОГРАНИЧЕНИЯ
- Демонстрационный словарь содержит около 100 слов. Для полноценной работы замените data.js.
- Переводы в демонстрационном наборе носят иллюстративный характер и не являются
  академически выверенными.
- Приложение не использует localStorage, fetch, eval, внешние запросы.
- Поиск выполняется по подстроке без учёта регистра одновременно по английскому слову
  и русскому переводу.
- Выводится не более 100 результатов.
- Приложение не проверялось в реальном браузере или iframe sandbox="allow-scripts"
  из-за ограничений среды разработки.

6. ИСТОЧНИКИ
Демонстрационные данные составлены на основе общеупотребительной лексики.
Ссылки на внешние источники не включены, так как приложение должно работать офлайн.

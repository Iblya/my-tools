Генератор безопасных паролей
============================

Что это
-------
Самостоятельное браузерное приложение на HTML, CSS и JavaScript.
Не требует интернета, сервера, регистрации или установки зависимостей.

Как работает
------------
- Пароль создаётся локально в браузере с помощью crypto.getRandomValues.
- Длина регулируется от 8 до 64 символов.
- Можно включать категории: заглавные, строчные, цифры, спецсимволы.
- Если категория включена, в пароле гарантированно есть хотя бы один символ из неё.
- Опция «Исключить похожие символы» убирает 0, O, 1, l, I.
- Кнопка «Скопировать» пытается использовать буфер обмена. Если окружение
  запрещает копирование, приложение показывает сообщение и не ломается.

Ограничения и точность
----------------------
- NIST SP 800-63B Revision 4 (2025) рекомендует длину 15+ символов для
  однофакторной аутентификации и не требует обязательной композиции.
  OWASP традиционно рекомендует минимум 10 символов и разнообразие категорий.
  Приложение по умолчанию включает все категории, но их можно отключить.
- Энтропия показана как приблизительная оценка; она не гарантирует стойкость
  конкретного пароля к целевым атакам.
- Приложение не проверяет пароль по базам утечек и не хранит историю паролей.
- В некоторых iframe с sandbox="allow-scripts" буфер обмена может быть
  недоступен. Это обрабатывается без поломки интерфейса.

Файлы
-----
index.html  — точка входа
style.css   — оформление
app.js      — логика
data.js     — наборы символов
README.txt  — этот файл

Как встроить
------------
1. В админке Tree Studio создайте страницу.
2. Загрузите ZIP с этими файлами в корне (без лишней внешней папки).
3. Выберите index.html как точку входа.
4. Сохраните и экспортируйте сайт.
Рекомендуемая высота iframe: 760–820 px.

ТЕТРИС ДЛЯ TREE STUDIO

1. Создайте страницу «Тетрис» в разделе «Игры».
2. Нажмите «Загрузить ZIP» и выберите tetris.zip без распаковки.
3. Стартовый файл: index.html. Рекомендуемая высота страницы: 1100 px.
4. Сохраните настройки, проверьте игру, экспортируйте весь сайт и обновите публикацию на GitHub.

Можно также распаковать архив и открыть index.html напрямую. Сервер, библиотеки, сеть и localStorage не нужны. Для клавиатуры сначала нажмите «Играть» или щёлкните по полю.

Управление:
← / A, → / D — движение;
↑ / W / X — поворот по часовой стрелке;
Z — поворот против часовой стрелки;
↓ / S — мягкое опускание;
Пробел — мгновенный сброс;
P / Esc — пауза;
Enter на игровом поле — начало/продолжение игры;
на телефоне — кнопки под полем, стрелки можно удерживать.

Семь фигур, случайные наборы по семь без пропусков, предпросмотр следующей фигуры и контур места падения. Поле 10×20 клеток. Каждые 10 убранных линий повышают уровень. Используется простая схема поворотов с поправками у стен и пола, не полная турнирная SRS-система. Фигура фиксируется через 450 мс после касания; число сбросов задержки движением ограничено.

Очки за 1/2/3/4 линии: 100/300/500/800 × текущий уровень. Мягкое опускание: 1 очко за клетку; мгновенное: 2. Комбо, T-spin и удержание фигуры не реализованы.

При переключении окна/вкладки включается автопауза. Рекорд действует только до обновления страницы, не записывается на диск и не отправляется в сеть. В файлах нет внешних библиотек, рекламы и сетевых запросов.

Проверены алгоритмы фигур, столкновения, очистка линий, очки, уровни, задержка фиксации, пауза, окончание и перезапуск игры, случайные последовательности ходов, обработчики интерфейса на модели DOM, импорт и экспорт Tree Studio. Полная визуальная проверка в настоящем браузере в среде сборки не выполнена.
